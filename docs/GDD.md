## 1. 콘셉트 검증 — 왜 '별빛 정원'인가 (대안 2개와 비교)

### 1.1 대안 콘셉트

| | **A. 별빛 정원** (채택) | B. 꼬마 우주 탐험대 | C. 마법 빵집 |
|---|---|---|---|
| 판타지 | 별 요정이 정원을 되살림, 매일 새 친구 | 로켓으로 매일 새 행성 방문, 미션 해결 | 요정 빵집 운영, 손님 주문을 단어·수로 해결 |
| 핵심 루프 | 친구 만남 → 배움 → 정원 회복 → 친구가 정원에 '산다' | 착륙 → 미션 → 행성 스탬프 | 주문 → 재료 모으기 → 빵 굽기 → 판매 |

### 1.2 평가 (5점 척도, 근거 포함)

| 기준 (가중치) | A 정원 | B 우주 | C 빵집 | 근거 |
|---|---|---|---|---|
| **매일 복귀 동기** (×3) | **5** | 4 | 3 | A는 "내일 누가 올까?"가 30일 내내 새 인물로 갱신. B의 새 행성은 풍경이라 정서 약함. C는 매일 같은 가게라 반복감 |
| **학습 내용의 자연스러운 운반자** (×3) | **5** | 3 | 3 | A는 친구 = 단어 5개 + 문장 1개의 '화자'. 캐릭터가 직접 말해주는 구조는 유아의 준사회적(parasocial) 학습 효과가 가장 큼. B/C는 주제(우주·음식)가 150단어 전 영역을 덮기 어려움 |
| **어휘 영역 커버리지** (×2) | **5** | 2 | 2 | 색·수·모양·동물·가족·몸·음식·옷·날씨·동작·감정·장소 모두 '정원 친구'가 들고 오면 됨. 우주/빵집은 가족·몸·날씨 연결이 억지 |
| **압박·경쟁 없음** (×2) | **5** | 4 | 2 | C는 손님 대기·시간 압박·돈 교환 구조가 IAP 게임 문법과 닮음(Kids 카테고리·부모 신뢰에 불리) |
| **정서적 애착·돌봄** (×2) | **5** | 3 | 3 | 돌봄(정원 되살리기)은 7세의 유능감·관계성 욕구(자기결정성 이론)를 동시에 충족 |
| **30일 구조 적합성** (×1) | **5** | 4 | 2 | 30마리 도감 → 30일째 전원 인사 피날레로 자연 종결 |
| **아트 제작비 (코드 SVG)** (×1) | **5** | 4 | 3 | 둥근 기본형 + 1개 시그니처 파츠 조합으로 30마리 생성 가능. 빵집은 소품이 많음 |
| **가중 합계 (최대 70)** | **70** | 49 | 36 | |

**결론:** A는 "매일 켜고 싶은 이유(새 친구)"와 "배울 내용(친구가 가르쳐 주는 말)"이 **같은 오브젝트**다. 동기 설계와 학습 설계가 분리된 B·C보다 구조적으로 우월하다. 또한 매주 마지막 날 '친구들과 복습 파티'는 이미 만난 친구들의 재등장이라 복습이 곧 보상이 된다.

### 1.3 이 콘셉트의 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 친구가 30마리라 아트 품질 편차 | §8.2 캐릭터 규칙(기본형 5종 × 파츠)으로 일관성 강제, Stage 5 리뷰 |
| 정원 '돌보기'가 방치형 게임처럼 흐를 위험 | 정원은 **학습 결과의 시각화**일 뿐, 별도 노동 루프(물주기 타이머 등) 금지 |
| 기존 캐릭터와 유사성 | 이름·실루엣 체크리스트(§8.4), Stage 5 ⑤ 리뷰에서 재검 |

## 2. 핵심 루프

### 2.1 하루 세션 (기본 15분)

```
[별 누르기] ─ 오디오 언락 제스처
    │
    ▼
① 친구 등장 (≈1분 30초)  ── 새 친구가 떨어지는 별처럼 착지 → 영어 인사
    │                         → 단어 5개: 그림 + 소리 + 쓰임 문장 (각 1회)
    ▼
② 정원 길 4정거장 (≈11분)  ── 스케줄러가 오늘의 4판을 배치
    │   정거장1 영어-새 단어   (단어 정원 등)       ~3분
    │   정거장2 한글·수·사고력 (한글 조각 등)       ~3분
    │   정거장3 파닉스         (소리 나비)          ~2분 30초
    │   정거장4 문장           (문장 기차 + 따라 말하기) ~2분 30초
    ▼
③ 별빛 심기 (≈1분)        ── 모은 별빛으로 친구의 집 자리가 꽃핀다
    ▼
④ 잘 자 인사 (≈40초)      ── 요정이 오늘 단어 3개를 불러줌
                              "정원이 잠들 시간이야. Good night!"
```

- 정거장 사이 이동은 **요정이 걸어가는 짧은 연출(2초)** — 로딩을 숨기는 동시에 "다음 것"의 기대감.
- 4정거장을 끝낸 뒤 시간이 남으면 **자유 놀이**(해금된 게임 복습 모드). 시간이 되면 현재 문제를 끝내고 ④로.
- 시간 제한 도달 시 **즉시 끊지 않는다**: 진행 중 문제 완료 → 잘 자 인사. (부모 설정 10/15/20분)

### 2.2 30일 메타 루프

```
새 친구 만남 ─▶ 배움(미니게임) ─▶ 별빛 획득 ─▶ 정원 회복 + 친구 입주
     ▲                                                    │
     └──── "내일 누가 올까?" 실루엣 예고 ◀─ 별자리 1칸 점등 ◀┘
```

- **내일 예고:** 잘 자 인사 마지막에 다음 친구의 **실루엣 + 첫 소리**만 보여준다 ("내일은… /m/ 소리 친구가 와!"). 궁금증 = 복귀 동기, 동시에 파닉스 예습.

### 2.3 주간 루프

| 요일 | 역할 |
|---|---|
| D1~D6 (각 주) | 새 친구 + 새 단어 5 + 새 문장 1 + 새 글자 1 |
| D7 (각 주 마지막) | **친구들과 복습 파티** — 그 주 친구 6마리가 모두 등장, 새 단어는 쉬운 '파티 단어' 5개, 챕터 챈트 공개 |

## 3. 30일 캘린더 (확정안)

### 3.1 설계 규칙

- **단어:** 하루 5개 × 30일 = **150개, 중복 0** (스크립트로 검증). 모두 그림으로 표현 가능한 고빈도 구체어.
- **문장 패턴:** 30개 모두 서로 다름. 친구의 첫 인사가 곧 그날의 패턴 예문.
- **파닉스 순서: 알파벳 순이 아닌 SATPIN 계열 순서** — s·a·t·p·i·n 6글자만으로 *sat, pin, tap, nap* 등 CVC를 만들 수 있어 **3주차부터 소리 합치기**가 가능. 알파벳 순으로 하면 CVC가 4주차 이후로 밀린다. (⚠ 승인 필요 §12)
- **친구 이름의 첫소리 = 그날 파닉스 글자** (Sami→/s/, Pip→/p/). "My name is Sami. /s/ /s/ Sami!" — 이름이 곧 파닉스 기억 고리. 모음 글자는 **짧은 모음**으로 시작하는 이름(Appy /æ/, Izzy /ɪ/, Olli /ɑ/, Ebbi /ɛ/, Uppy /ʌ/)으로 TTS 오독을 피한다. X는 첫소리가 /z/라 **끝소리(box)** 로 가르치고 친구 이름은 Dexi(/ks/).
- **복습:** 모든 단어는 1일·3일·7일 뒤 **다른 미니게임** 안에서 재등장. D7·14·21·28은 주간 전체 복습 파티.

### 4.2 영어 발화 타이밍 (손맛의 핵심)

- 영어 학습 음성은 한국어 지시 **종료 후 250ms 뒤** 시작 (겹침 금지, 오디오 큐 직렬화).
- 정답 순간: 효과음(80ms) → 120ms 뒤 정답 단어 재발화 → 칭찬. 단어가 칭찬에 묻히지 않게.
- 문장 기차 완성: 기차가 출발하며 **칸이 지날 때마다 해당 단어 하이라이트 + 발화**(단어 간 350ms), 이후 전체 문장 자연 속도 1회.

```
window = 최근 10문제 (최소 5문제 이상 쌓인 후 판정)
```

## 9. 기술 설계

### 9.1 스택 결정: **PixiJS v8** (Phaser 3 대신)

| 기준 | PixiJS v8 | Phaser 3 | 판단 |
|---|---|---|---|
| 번들 크기 (첫 로딩 3초) | 렌더러만, 트리셰이킹 가능 | 풀 프레임워크, 물리·로더 등 포함 | **Pixi 유리** — 3초 목표에 여유 |
| 필요한 기능 | 렌더·인풋·텍스처 | 씬·트윈·인풋·오디오·물리 내장 | 물리 불필요. 씬/트윈은 200줄 내 자체 구현 |
| 로직 테스트 용이성 | 렌더러가 얇아 **로직을 순수 TS로 분리하기 쉬움** | 씬 수명주기에 로직이 얽히기 쉬움 | **Pixi 유리** — TDD 90% 목표 |
| 오디오 | 없음 → Web Audio 직접 | 자체 사운드 매니저 | 어차피 절차적 생성·TTS 큐를 직접 짜야 함 |
| DOM UI 공존 | 캔버스 + DOM 오버레이 자연스러움 | 가능 | 부모 화면·접근성은 DOM으로 |
| SVG 코드 드로잉 | Graphics API + SVG 파싱 지원 | 텍스처로 로드 | 동등 |
| 개발 속도 | 느림(직접 구현 多) | 빠름 | **Phaser 유리** — 수용 가능한 비용 |

**결정 이유 한 줄:** 이 게임의 가치는 물리·복잡 씬이 아니라 *학습 로직의 정확성*과 *가벼움*에 있다. 렌더러만 빌리고 두뇌(스케줄러·SRS·적응형)는 순수 TS로 두는 구조가 테스트·성능·Capacitor 이식 모두에 유리하다.

**부가 라이브러리 (최소):** `idb`(IndexedDB 래퍼, ~1KB) · `vite-plugin-pwa`(SW) · 개발 전용 `zod`(데이터 스키마 검증 — 런타임 번들 미포함) · `fake-indexeddb`(테스트) · `vitest` · `eslint` · `prettier`.

### 9.2 성능 예산

### 9.3 오디오 아키텍처

```
VoiceLine ID ("en.word.red", "ko.prompt.tapButterfly", "en.sentence.d01")
        │
        ▼
audio-manifest.json  ─ { id, lang, text, file?: "audio/en/word/red.m4a" }
        │
        ▼
VoicePlayer: file 있으면 <AudioBuffer> 재생 → 없으면 speechSynthesis(lang, rate)
        │
        ▼
직렬 큐 (겹침 금지, 우선순위: 학습 > 지시 > 칭찬, cancel 가능)
```
- 원어민 녹음 교체 = 파일을 넣고 매니페스트에 `file`만 채우면 끝 (코드 수정 0). 가이드는 Stage 6 `docs/audio.md`.
- 효과음·챕터 루프 음악·챈트 반주 = Web Audio 오실레이터/노이즈로 코드 생성(5음계 펜타토닉 → 불협 없음).

### 9.4 저장

- IndexedDB `starlight-garden` DB, store: `save`(단일 문서), `recordings`(Blob), `meta`.
- 세이브 문서에 `schemaVersion`. 로드 시 `migrations[v→v+1]` 체인 적용, 각 마이그레이션은 단위 테스트 필수.
- `navigator.storage.persist()` 요청 + 부모 화면 **진도 백업 파일 내보내기/가져오기**(로컬 JSON 다운로드, 네트워크 없음).

## 부록 A. 30개 문장 패턴 한눈에

1 I like ___. · 2 This is a ___. · 3 It is ___. · 4 I have ___. · 5 Look at the ___! · 6 How many ___? · 7 I see ___. · 8 What is it? It's a ___. · 9 Where is the ___? · 10 Is it a ___? · 11 This is my ___. · 12 Touch your ___. · 13 Wash your ___. · 14 I love my ___. · 15 I want ___. · 16 Do you like ___? · 17 I don't like ___. · 18 Put on your ___. · 19 Is this your ___? · 20 It's ___ today. · 21 What color is it? · 22 I can ___. · 23 Can you ___? · 24 Let's ___! · 25 I am ___. · 26 Are you ___? · 27 I'm at the ___. · 28 It's in / on / under the ___. · 29 Thank you, ___! · 30 You are my ___.

- 흐름: **서술(I like/It is) → 지시(Touch/Wash/Put on) → 질문(Where/Is it/Do you/Can you/Are you) → 관계·감정(I love/Thank you/You are my friend)**. 질문형은 2주차부터 도입해 '대답하기'를 문장 기차 L3(질문+대답)에서 연습.
- 복수형 -s(hands, carrots, shoes)는 규칙 설명 없이 **청킹으로 노출**만 한다.

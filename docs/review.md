# Stage 5 리뷰 기록

## 진행 상황 (정직한 기록)

계획은 서브에이전트 5명(① 만 7세 플레이테스터 ② 아동 발달·교육 ③ 유아 EFL ④ 성능·접근성 ⑤ 아동 개인정보·App Store)의 병렬 리뷰였습니다.
**5명 모두 API 사용량 한도(HTTP 429)로 결과를 내기 전에 중단되었습니다.** 그래서 아래는 같은 5가지 관점으로 한 사람이 점검한 결과와 측정값입니다. 사용량 한도가 풀리면 병렬 리뷰를 다시 돌려 이 문서를 보완해야 합니다.

## 관점별 점검과 조치

| 관점            | 점검 내용                                      | 결과 / 조치                                                                                                                                                                                                                         |
| --------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 플레이테스터  | 글 없이 진행 가능 여부, 막다른 화면, 터치 크기 | 모든 화면에 귀 버튼과 🏡 버튼이 있고, 버튼 히트박스는 120 단위(아이폰 기준 64px 이상). 허브에서 요정이 정거장 돌을 가리던 문제 수정. Sami가 기존 캐릭터를 닮아 보여 꽃봉오리 디자인으로 변경                                        |
| ② 아동 발달     | 세션 길이, 압박 요소, 보상                     | 연속 출석 끊김이나 랜덤 보상이 없음. 시간 제한 시 문제를 끝낸 뒤 잘 자 인사로 마무리. 막히는 아이에게 도움 모드 추가                                                                                                                |
| ③ EFL           | 파닉스 그림의 첫소리, 문장 문법, TTS 함정      | 첫소리 목록은 **철자가 아니라 소리 기준**(circle/three/one 제외, c·k 동일 소리 처리, x는 끝소리). 글자 이름 TTS 보정(a→"ay"). **남은 한계: 음소는 원어민 녹음 전까지 글자 이름으로 대신 읽음** → [audio.md](audio.md) 1순위         |
| ④ 성능·접근성   | 프레임마다 다시 그리기, 누수, iOS              | 얼굴 그래픽은 상태가 바뀔 때만 다시 그림. 장면을 나가면 스크립트와 내비게이션이 멈춤(수명주기 가드). 파티클 풀링과 저전력 모드 대응. 확대 금지 제거                                                                                 |
| ⑤ 개인정보·Kids | 네트워크, 수집, 녹음, 게이트                   | 네트워크 요청 0(CSP `connect-src 'self'`). 의존성은 pixi.js와 idb뿐. 녹음은 기본 꺼짐, 보호자만 켤 수 있고 기기에만 보관(보관 기간 설정·전체 삭제 가능). 설정·초기화·백업·인쇄는 모두 게이트 뒤. 제출 체크리스트는 [ios.md](ios.md) |

## 남은 과제

1. 병렬 서브에이전트 리뷰 재실행 (사용량 한도가 풀린 뒤)
2. 원어민 음소·단어 녹음 (파닉스 품질에 가장 큰 영향)
3. 실제 아이 1~2명의 사용성 테스트 → 시뮬레이션 정답 확률 모델 보정
4. 실제 iPhone(구형 기종 포함)에서 60fps, 오디오, 음성 합성 확인

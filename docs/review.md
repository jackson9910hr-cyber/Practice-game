## 적용한 수정 (요약)

**버그 / 안정성**

- 기억 카드·대답 카드의 연타 가드. 대답은 "누르면 듣기 → ✔로 확정"으로 분리하고 힌트 사다리를 적용
- 드래그 재작성: pointercancel·blur·장면 전환·객체 파괴 시 모두 해제
- 죽은 객체에 tween을 걸지 않음 + ticker 예외 격리 (화면 정지 방지)
- safe-area는 캔버스 안쪽 레이아웃으로 처리 (노치 기기에서 버튼 잘림 해결)
- 배경 별 Graphics 누수 제거 (하늘/땅 분리, 복원 트윈은 땅만 다시 그림)
- 취소된 음성이 이어서 재생되지 않도록 epoch 체크 (이름 읽기, 패턴, 기차, sayAll)
- 오디오 생명주기: 숨김 시 suspend + 음악 정지, 복귀 시 재개, iOS 중단(Siri·전화) 복구, 녹음 중 `play-and-record` 세션, 음성 합성 paused 복구

**학습 내용**

- **음소 대체 방식 변경**: 원어민 녹음이 없으면 글자 이름 대신 **키워드 단어만** 들려줌. 소리 합치기는 단어 전체를 천천히 읽으면서 글자를 하나씩 강조
- c/k/q 같은 소리 글자는 서로 오답 보기로 쓰지 않음. x는 끝소리 전용(첫소리 문제 제외, "끝나는 말" 예고 문구). ㅐ/ㅔ(/æ/–/ɛ/)만 다른 CVC 보기 제외
- 파닉스 그림 정리: c/k 목록 분리, f에 fox, x에 socks, lip(=mouth 그림) 삭제, 키워드 tiger·goat·igloo, ox→otter, envelope→elevator, queen/king 교체
- 데이터 수정: "Thank you, Mom/Grandma/Dad!", scared=무서워하는, jump=깡충 뛰다, "Let's sleep/eat!", "This is a baby.", "I want grapes!", read는 "reed"로 읽기
- 헷갈리는 그림 쌍(sun/sunny, cloud/cloudy, sleep/sleepy/tired, night/bridge/sky…)은 같은 판 보기에 함께 나오지 않음. hide 🫣, cook 🧑‍🍳, fly·bridge·igloo는 코드로 그림
- 친구가 "Hi! I'm Appy!"처럼 이름을 말함 (이름 첫소리 = 오늘 글자)
- 한글: 조각을 집으면 음가("그", "아")를 들려주고, 흐린 정답 글자는 틀린 뒤 힌트로만 보여 줌
- 수: 셀 때는 한국어 고유어(하나, 둘…), 정답에서 한국어와 영어를 함께 들려줌
- 색각 이상 대응: 패턴 꽃 가운데에 색마다 다른 표시
- 사고력 칸 순환: 한글·수는 약 2일, 패턴·개미는 약 4일마다

**동기·정서**

- 별빛은 **정거장을 끝낼 때마다 고정 5개**(정답 수와 무관: 느린 아이도 같은 보상)
- 칭찬: 도움받은 뒤에는 과정 칭찬("끝까지 찾았구나!"), 영어·한국어 50:50, 사람 칭찬 문구 교체
- 남은 시간 2분 알림, 시간이 다 되면 그 판을 완료로 처리하고 잘 자 인사
- 잘 자 인사 뒤에는 정원이 잠듦(다시 놀기 버튼 없음). 🏡는 두 번 눌러야 나감. 잠긴 돌을 누르면 안내
- 틀린 보기는 흐려지고 다시 누를 수 없음. 도움 단계 동안 나비가 멈춤. 따라 말하기 간격은 음절 수에 비례

**개인정보 / 스토어**

- 앱 안 **개인정보 처리방침 전문** (`src/data/privacy.json`, 보호자 화면) + `public/privacy.html`
- 음성 합성은 **기기 내장 음성만** 사용 (Chrome의 온라인 음성 제외)
- 녹음 버튼은 마이크 권한이 이미 허용된 경우에만 표시. 녹음을 끌 때 기존 녹음 삭제 여부를 물음. 기본 보관 기간 1일, 1시간마다·복귀 시 보관 기간 적용, 녹음 개별 삭제
- 백업을 불러와도 녹음은 꺼진 상태. 게이트 잠금은 새로고침해도 유지
- IP 위험 이름 변경: Mimi→Mobi, Gomo→Soli, Ruby→Reni. 요정 Twinkle에 고유 리본 추가

**접근성**

- 보호자 다이얼로그: 배경 `inert`, 포커스 이동·복원, Esc로 닫기, 버튼 레이블, `role=status`. 열려 있는 동안 게임 렌더링 정지
- Lighthouse(모바일): 성능 98 / **접근성 100** / 권장사항 100

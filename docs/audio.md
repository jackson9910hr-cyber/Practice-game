# 게임 음성과 원어민 녹음 교체

## 지금 들어 있는 소리

| 소리                                                                                                               | 방식                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **영어 783줄** (단어 150, 쓰임 문장, 문장 기차 카드, 친구 인사·이름, 챈트, 숫자, 방향, 칭찬, **파닉스 음소 26개**) | 게임에 **녹음 파일(MP3)로 포함**. 기기와 상관없이 같은 목소리이고, 오프라인에서도 재생됨                      |
| 한국어 안내 약 340줄                                                                                               | 기기 한국어 음성(iOS "유나")으로 읽음. 공개된 한국어 음성 합성 모델이 없어 기기 음성을 씀. 녹음으로 교체 가능 |
| 효과음, 챕터 음악, 챈트 반주, 배경 소리(꽃밭 풍경, 연못 물방울·개구리, 숲 새소리, 하늘 바람, 밤 귀뚜라미)          | Web Audio로 코드에서 생성 (파일 없음)                                                                         |

**영어 녹음 만들기:** `npm run gen:voice`(`scripts/gen-voice.py`)로 만듭니다.

- 음성 엔진: Piper 신경망 음성 합성(MIT)
- 모델: `en-us-libritts-high`. LibriTTS 데이터(CC BY 4.0)로 학습했으며, 출처는 보호자 화면과 이 문서에 표기합니다.
- 목소리: 904명 중 화자 172번(여성, 약 225Hz). 잡음 대비 신호 세기와 음성 인식 테스트(단어 오류율 2%)로 골랐습니다.
- 문장은 4번씩 만들어 음성 인식기가 가장 잘 알아듣는 것을 남겼습니다.
- 음소는 IPA로 직접 합성합니다. 끊기는 무성음(p, t, k)은 "어" 없이 짧게, 울리는 소리(b, d, g)는 아주 짧은 모음을 붙이고, 늘일 수 있는 소리(s, m, f…)는 길게 냅니다.

**재생 방식:** 먼저 `audio-manifest.json`의 `file`을 재생합니다. 파일이 없거나 불러오지 못하면 Web Speech(영어 en-US 속도 0.8, 한국어 ko-KR)로 대신 읽습니다. 아이폰 무음 스위치가 켜져 있어도 들리도록, 첫 탭에서 무음 오디오를 반복 재생해 재생용 오디오 세션을 유지합니다. **코드는 고칠 필요가 없습니다.**

```json
"en.word.red": { "lang": "en-US", "text": "red", "file": "audio/en/word/red.m4a" }
```

## 원어민 녹음으로 바꾸는 순서

1. 파일을 `public/audio/...`에 넣습니다. 권장 형식은 AAC `.m4a`(mono, 44.1kHz, 64~96kbps)이며, 앞뒤 무음을 100ms 이하로 자릅니다.
2. 매니페스트에서 해당 ID의 `file`에 `public/` 기준 경로를 적습니다.
3. `npm run gen:audio`를 실행합니다. 새 문장은 추가되고, 이미 적어 둔 `file` 값은 보존됩니다. 사람이 녹음한 파일은 `gen:voice`가 절대 덮어쓰지 않습니다(`source` 표시가 없는 파일).
   - 문장 텍스트를 바꾸면 생성된 녹음은 자동으로 비워져 `gen:voice`로 다시 만들어집니다.
   - 사람 녹음이면 "다시 녹음 필요" 목록에 표시됩니다.
4. `npm run validate:data`로 누락을 확인하고, `npm run build`로 빌드합니다. 서비스 워커가 방문한 파일을 캐시하므로 이후에는 오프라인에서도 재생됩니다.

## 녹음 우선순위 (효과가 큰 순서)

| 순위 | ID 패턴                               | 개수        | 이유                                                                                                                                                                                                                                     |
| ---- | ------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | `en.phoneme.<a–z>`                    | 26          | **현재 음소는 TTS가 글자 이름으로 대신 읽습니다**(예: c → "C"). 파닉스 효과를 내려면 순수한 소리(/k/, /æ/ …)를 녹음해야 합니다. 짧은 모음은 /æ/ /ɛ/ /ɪ/ /ɑ/ /ʌ/로 녹음합니다. 무성 자음 뒤에 "어" 모음을 붙이지 마세요(ㅋ가 아니라 /k/). |
| 2    | `en.word.*`, `en.pic.*`               | 150 + 40    | 단어는 또박또박, 한 번씩                                                                                                                                                                                                                 |
| 3    | `en.greet.*`, `en.t.*`                | 30 + 약 180 | 친구 인사와 문장. 자연스러운 속도보다 약간 느리게                                                                                                                                                                                        |
| 4    | `ko.*`                                | 약 250      | 한국어 안내(다정한 반말). 가족 목소리로 녹음하면 아이의 반응이 특히 좋습니다                                                                                                                                                             |
| 5    | `en.num.*`, `en.dir.*`, `en.praise.*` | 약 40       | 숫자, 방향, 칭찬                                                                                                                                                                                                                         |

## 파일 이름 규칙 (권장)

ID의 점을 슬래시로 바꿉니다. 예: `en.word.red` → `audio/en/word/red.m4a`, `ko.hint.listen` → `audio/ko/hint.listen.m4a`.

## 확인

보호자 메뉴 → **음성 테스트**. 녹음 파일을 불러오지 못하면 자동으로 TTS로 돌아가므로 게임이 멈추지 않습니다.
